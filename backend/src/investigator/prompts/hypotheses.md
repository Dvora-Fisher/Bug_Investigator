Task: understand the bug report and propose hypotheses about its root cause.

You receive the bug description, any error output, the project structure, and excerpts of files named in the error output.
1. Identify the main programming language from the file names and contents.
2. Summarise the bug in one or two sentences: expected behaviour versus actual behaviour.
3. Propose up to 3 NEW hypotheses, most likely first. Each names a specific file and, if possible, a function.
   A good hypothesis explains the exact symptom, not just "something is wrong in X".
Do not repeat hypotheses that were already refuted; learn from why they failed.
